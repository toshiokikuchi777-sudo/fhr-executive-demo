# FHR 経営者向けプレゼンデモ

日本・マレーシア・香港の架空3店舗を、経営者が一つの画面で確認する操作デモです。実際のFHRの展開地域・数値・店舗情報ではありません。

## 開く

公開デモ：[FHR 経営コンソール](https://toshiokikuchi777-sudo.github.io/fhr-executive-demo/)

GitHub Pagesでログインなしに閲覧できます。ダウンロードした `docs/index.html` をブラウザーで開くと、通信なしでも動作します。

## 説明の順番

最初に「この資料について」が開きます。右上または導入ページの「説明に沿って見る」を押すと、次の6画面を順に確認できます。「デモを見る」から自由に操作することもできます。

1. この資料について：売上・利益・経費、会員の増減、スタッフの対応を何のために管理するかを説明します。AIによる報告の要約・変化の整理・対応案の下書きは本番導入時の活用構想として紹介し、作業時間・対応状況・会員の継続で効果を確かめる進め方を共有します。
2. 経営概況：全店舗を円換算で俯瞰し、日本・マレーシア・香港に絞り込みます。指標・グラフ・確認事項・店舗一覧は選択した国・地域に連動します。国・地域別の比較カードは常に全3地域を表示します。
3. 店舗の課題：店舗を選ぶと、現地通貨の業績と会員・対応状況を確認できます。説明ツアーではマレーシアの店舗Bを取り上げ、退会率と未対応フォローを確認します。両者の因果関係は断定しません。
4. 改善アクション：「担当・期限を決める」を押して、担当責任者と確認期限をデモ内で設定します。
5. 効果を考える：対応完了率、退会率、作業時間を分けて評価。マレーシアの店舗Bを例に、人数と会費の仮定を変え、1か月分の追加会費売上をMYRで試算します。
6. 導入プラン：まず1〜2店舗で確認・試行・評価する進め方を説明します。

「次へ」「前へ」で移動できます。自由操作中も左メニューから各画面へ移動できます。`#overview` など既存の各画面への直接リンクも利用できます。デモ内のタスクと試算はメモリー上だけに保持し、リロードまたは「デモをリセット」で初期状態に戻ります。リセット時は導入ページを表示します。

## 通貨と集計

- 店舗A：日本・JPY、店舗B：マレーシア・MYR、店舗C：香港・HKD。国・地域と3店舗の構成は説明用の仮定です。
- 経営概況の合計・国別集計・推移は円換算。店舗詳細は現地通貨です。異なる現地通貨の金額を直接足し合わせません。
- 固定レートは `1 MYR = 30円`、`1 HKD = 20円`。実勢レートではなく、比較用の架空の前提です。当月・前月・6か月の推移に同じレートを適用します。
- 全店舗の9月売上は18,750,000円、費用14,820,000円、簡易営業利益3,930,000円。会員数は2,160人、未対応は19件です。
- 退会率は各店舗の率の単純平均ではなく、退会人数の合計 ÷ 月初会員数の合計で計算します。
- 実導入では換算レートの基準、対象期間、会員数や利益の定義をそろえてから比較します。

## 範囲

- AI欄は事前作成した表示例で、AIサービスには接続しません。週次報告の要約、気になる変化の整理、対応案や共有文の下書きによる効率化は本番導入時の構想で、デモにAI機能は実装していません。
- 数字の集計・計算はシステムが行い、AIは説明や下書きを支援する想定です。提案の採用や会員への連絡は人が確認して決めます。
- 現在のデモは店舗別の集計と対応管理の画面例です。集客・個別トレーニングは導入時の追加案で、会員の詳しい情報や見学予約・広告などの連携範囲は導入前に確認します。
- 効率化や業績改善を保証するものではありません。1〜2店舗で作業時間・対応状況・会員の継続を比較し、削減できた時間と導入・運用費用、季節やキャンペーンの影響も踏まえて評価します。
- タスク登録はデモ内のみで、通知や外部保存は行いません。
- 実際の認証、店舗別認可、会員管理、決済、バックアップは実装していません。
- 一元表示は、全ての国の個人情報を一カ所に移すことを意味しません。本番では各国・契約・既存システムの条件を確認し、共有が認められた経営情報を集計して表示する設計を想定しています。
- 90日は導入検討の例であり、納期・効果・費用の約束ではありません。

## 検証

`node --test tests/data.test.cjs` で集計・試算・通貨換算・整合性のテストを実行します。
`node --check docs/app.js` でUIスクリプトの構文を確認します。

導入ページ追加時に、初期表示、導入ボタン、6画面の移動、説明の開始・順送り・戻る・終了、リセット、既存画面への直接リンク、ブランドリンクを実ブラウザーで確認しました。390pxと320pxの画面幅で、全6画面に横方向のはみ出しがないことも確認済みです。ブラウザーのコンソールエラーはありません。

AI活用説明の追加時は、報告例から店舗Bの根拠へ進む操作、効果画面への移動、末尾のデモ開始、リセットを確認しました。拡張した導入ページは768px・390px・320px幅で横にはみ出さず、構文検査と既存の9テストも成功しています。

国内外の一元表示の追加時は、14テストで通貨換算・国別集計・全店舗合計・前月比較・推移の整合性を確認しました。実ブラウザーで国・地域の切替、店舗詳細の現地通貨、営業利益グラフ、全店舗へ戻る操作、6画面の説明ツアーとリセットを確認しています。導入・経営概況・店舗・導入プランは320px・390px・768px・1024px・1265pxの画面幅でページと主要金額のはみ出しがなく、320px幅の日本・香港の店舗金額も確認済みです。ブラウザーのコンソールエラーはありません。
