# FHR 経営者向けプレゼンデモ

架空の3店舗を使った、操作可能な説明用デモです。実際のFHRの数値・店舗情報ではありません。

## 開く

公開デモ：[FHR 経営コンソール](https://toshiokikuchi777-sudo.github.io/fhr-executive-demo/)

GitHub Pagesでログインなしに閲覧できます。ダウンロードした `docs/index.html` をブラウザーで開くと、通信なしでも動作します。

## 3分の説明順

右上の「3分プレゼン開始」を押します。

1. 経営概況（約30秒）：売上・利益・会員数を確認。全体は増収でも、店舗ごとに状況が異なることを示します。
2. 店舗の課題（約40秒）：店舗Bの退会率と未対応フォローを確認。両者の因果関係は断定しません。
3. 改善アクション（約50秒）：「担当・期限を決める」を押して、担当責任者と確認期限をデモ内で設定します。
4. 効果を考える（約30秒）：対応完了率、退会率、作業時間を分けて評価。人数と会費の仮定を変え、1か月分の追加会費売上を試算します。
5. 導入プラン（約30秒）：まず1〜2店舗で確認・試行・評価する進め方を説明します。

「次へ」「前へ」で移動できます。自由操作中も左メニューから各画面へ移動できます。デモ内のタスクと試算はメモリー上だけに保持し、リロードまたは「デモをリセット」で初期状態に戻ります。

## 範囲

- AI欄は事前作成した表示例で、AIサービスには接続しません。
- タスク登録はデモ内のみで、通知や外部保存は行いません。
- 実際の認証、店舗別認可、会員管理、決済、バックアップは実装していません。
- 90日は導入検討の例であり、納期・効果・費用の約束ではありません。
- 通貨MYRと3店舗は説明用の仮定です。

## 検証

`node --test tests/data.test.cjs` で集計・試算・整合性の9テストを実行します。
`node --check docs/app.js` でUIスクリプトの構文を確認します。
実ブラウザーで5画面の遷移、店舗切替、タスク登録・変更、売上試算、プレゼン順送り・終了・リセットを確認。390pxと320px幅で5画面に横方向のはみ出しがないことを確認済みです。

## ファイル

## 公開の更新

GitHub Pagesの公開元は `main` ブランチの `/docs` です。`docs` 内の変更を検証して `main` にプッシュすると、GitHub Pagesが更新されます。秘密情報や実際の顧客データは追加しないでください。
